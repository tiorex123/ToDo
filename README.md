# 📝 Lista de Tarefas (To-Do List)

Uma aplicação web simples, limpa e funcional desenvolvida para o gerenciamento diário de tarefas, permitindo adicionar, marcar como concluídas e remover pendências de forma prática.

## 🚀 Funcionalidades

- **Adicionar Tarefas:** Insira novas pendências rapidamente na sua lista.
- **Marcar Conclusão:** Conclua tarefas com um clique, aplicando um efeito visual indicativo.
- **Remover Tarefas:** Exclua itens que não são mais necessários.
- **Persistência Local (Opcional):** Dados salvos no navegador para não perder suas anotações ao recarregar a página.
- **Design Responsivo:** Interface otimizada para uso em computadores e dispositivos móveis.

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando tecnologias web essenciais, sem o uso de frameworks complexos:

- **HTML5:** Estruturação semântica dos elementos.
- **CSS3:** Estilização moderna e layout responsivo.
- **JavaScript (Vanilla):** Manipulação do DOM, gerenciamento de eventos e lógica da aplicação.
